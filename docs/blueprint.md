# **App Name**: NDC Preschooler's Church

## Core Features:

- Resource Directory: Curate a categorized directory of links to chants, songs, schedules, announcements, and other resources.
- Roster Management: Manage and display weekly volunteer and staff rosters.
- AI Link Assistant: Generative AI tool to automatically categorize newly added URLs, minimizing the need to tag manually. This is a tool.
- Content Management: Easily add, update, and delete schedules, announcements, and videos.
- Admin Access: Grant admin privileges based on password input, allowing roster and announcement management.

## Style Guidelines:

- Primary color: Cheerful light blue (#74B9FF) to create a welcoming and calming environment.
- Background color: Soft, desaturated off-white (#F0F8FF) to provide a clean and gentle backdrop.
- Accent color: Gentle light green (#A8E6CE) to add a touch of freshness and highlight important elements.
- Body and headline font: 'PT Sans', a modern sans-serif font providing a balance of readability and a touch of warmth suitable for all text.
- Use friendly, age-appropriate icons, ensuring they are easily recognizable.
- Design a simple, intuitive, modern, minimal, and sleek layout that allows caregivers to easily access and share resources.
- Subtle transitions and animations to improve the user experience, without distracting the user.
